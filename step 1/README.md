## اطلاعات دانشجو

- **نام:** رضا دهقانی
- **درس:** آزمایشگاه هوش مصنوعی
- **استاد:** خانم جوکار
- **پروژه:** تشخیص اعداد دست نویس
- **جلسه سوم - گام اول**

---

## بیان مسئله

هدف این پروژه طراحی یک عامل هوشمند برای تشخیص اعداد دست نویس است. ورودی عامل، تصاویر اعداد دست نویس (۰ تا ۹) می باشد و خروجی آن، عدد تشخیص داده شده به همراه میزان اطمینان است. این مسئله یکی از مسائل کلاسیک در حوزه یادگیری ماشین و بینایی کامپیوتر محسوب می شود و کاربردهای زیادی در سیستم های تشخیص کد پستی، چک های بانکی و فرم های اداری دارد.

---

## تحلیل PEAS

| بخش | شرح |
|------|------|
| **Performance (معیار عملکرد)** | دقت (Accuracy)، صحت (Precision)، فراخوانی (Recall)، امتیاز F1، زمان پیش بینی و نرخ خطا |
| **Environment (محیط)** | مجموعه داده ای از تصاویر اعداد دست نویس ۸×۸ پیکسل (دیتاست digits از scikit-learn) شامل ۱۷۹۷ نمونه از ۱۰ کلاس (ارقام ۰ تا ۹) |
| **Actuators (محرک ها)** | نمایش عدد تشخیص داده شده، نمایش امتیاز اطمینان برای هر کلاس، ثبت نتیجه در خروجی |
| **Sensors (حسگرها)** | دریافت تصاویر ورودی از فایل یا دیتاست، خواندن مقادیر پیکسل ها (سطوح خاکستری ۰ تا ۱۶) |

---

## جدول ویژگی های محیط

| ویژگی | وضعیت | توضیح |
|--------|--------|--------|
| **Fully Observable / Partially Observable** | Fully Observable | عامل به تمام پیکسل های تصویر ورودی دسترسی کامل دارد و هیچ بخشی از تصویر پنهان نیست. |
| **Single Agent / Multi Agent** | Single Agent | تنها یک عامل تصمیم گیرنده وجود دارد که تصاویر را یکی یکی پردازش می کند. |
| **Deterministic / Stochastic** | Stochastic | فرآیند آموزش مدل شامل تصادف گرایی است (مقداردهی اولیه وزن ها، تقسیم داده ها)؛ نتایج هر بار اجرا ممکن است کمی متفاوت باشد. |
| **Episodic / Sequential** | Episodic | هر تصویر به صورت مستقل پردازش می شود و پیش بینی یک تصویر روی تصاویر بعدی تاثیر نمی گذارد. |
| **Static / Dynamic** | Static | داده ها در حین پیش بینی تغییر نمی کنند. محیط ثابت است و عامل فقط تشخیص را انجام می دهد. |
| **Discrete / Continuous** | Discrete | فضای خروجی گسسته است: ۱۰ کلاس برای ارقام ۰ تا ۹. |

## معیار ارزیابی

برای سنجش عملکرد مدل از معیارهای زیر استفاده می شود:

| معیار | فرمول / توضیح | اهمیت |
|-------|---------------|--------|
| **Accuracy (دقت)** | `(TP + TN) / Total` — نسبت کل پیش بینی های درست | معیار اصلی و کلی عملکرد |
| **Precision (صحت)** | `TP / (TP + FP)` — از بین مواردی که مدل مثبت تشخیص داد، چند درصد واقعاً مثبت بودند | برای کلاس های نامتوازن مهم است |
| **Recall (فراخوانی)** | `TP / (TP + FN)` — از بین موارد مثبت واقعی، چند درصد درست تشخیص داده شدند | نشان دهنده توانایی مدل در پیدا کردن نمونه های مثبت |
| **F1-Score** | `2 × (Precision × Recall) / (Precision + Recall)` — میانگین هماهنگ صحت و فراخوانی | تعادل بین Precision و Recall |
| **Confusion Matrix** | ماتریس ۱۰×۱۰ از پیش بینی های درست و اشتباه | تحلیل دقیق خطاها برای هر کلاس |
| **میانگین و انحراف معیار** | میانگین Accuracy روی ۱۰۰ اجرا با seedهای مختلف | سنجش پایداری مدل |
